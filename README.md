## 1. 概要

複数企業の選考状況・メモ・タグを一元管理し、就職活動を効率化するWebアプリケーション。

### 1.1 目的

- 複数企業の選考ステータスを可視化・追跡する
- 企業ごとのメモをテンプレートに沿って構造的に記録する
- タグでの分類・検索により情報を素早く参照できる
- 企業の強み・顧客・競合などの研究情報を一元管理する
- 各企業のマイページID・パスワードを一元管理する
- 説明会・面接などの日付を管理し、日付順での並び替えを行う

### 1.2 対象ユーザー

就職活動中の学生・転職活動中の社会人（個人利用）

## 2. ユーザー認証・設定

### 2.1 機能一覧

| 機能 | 優先度 | 概要 |
|------|--------|------|
| メール / パスワード登録・ログイン | 必須 | NextAuth.js v5 の Credentials Provider を使用 |
| ログアウト | 必須 | セッション破棄 |
| パスワードリセット | 必須 | メールアドレスで本人確認後、その場で新パスワードを設定 |
| ロゴ・アイコンのアップロード | 必須 | 画像をBase64でDB保存、サイドバーに表示 |
| アカウント削除（退会） | 必須 | 全データ（企業・メモ・タグ）をCASCADEで完全削除 |
| Google OAuth ログイン | Nice to have | NextAuth.js の Google Provider を使用 |

### 2.2 ログイン画面のバリデーション

| 状況 | エラーメッセージ |
|------|----------------|
| 両方未入力でログインボタン押下 | メールアドレスとパスワードは必須です |
| どちらか一方のみ入力 | メールアドレスとパスワードは両方入力してください |
| 両方入力済みだが認証失敗 | メールアドレスまたはパスワードが違います |

### 2.3 パスワードリセットフロー

1. ログイン画面の「パスワードを忘れた方はこちら」をクリック
2. メールアドレスを入力 → 存在しない場合はエラー表示
3. 新パスワードを2回入力（確認用）してボタンをクリック
4. DB上のパスワードが更新され、ログイン画面へリダイレクト
5. 「✅ パスワードを更新しました」のメッセージが表示される

### 2.4 その他の仕様

- 未ログイン状態でのアクセスは `/auth/login` へリダイレクト
- セッションはJWT戦略で管理
- ユーザーデータは完全に分離（他ユーザーのデータは参照不可）
- アカウント削除は確認ダイアログを2段階で表示（誤操作防止）
- ロゴ画像はPNG / JPG / SVG に対応、推奨サイズ 256×256px

## 3. 企業管理

### 3.1 機能一覧

| 機能 | 優先度 | 概要 |
|------|--------|------|
| 企業の追加 | 必須 | 手入力フォームで登録 |
| 企業の編集 | 必須 | 登録済み企業情報の更新・保存後に詳細画面へ自動遷移 |
| 企業の削除 | 必須 | 関連するメモ・タグ付けも連動削除 |
| 選考ステータス管理 | 必須 | 編集画面でのみ変更可能（詳細画面は表示のみ） |
| 企業一覧表示 | 必須 | リスト形式で一覧表示 |
| フィルタリング | 必須 | ステータス・タグで絞り込み |
| キーワード検索 | 必須 | 企業名でのキーワード検索 |
| 並び替え | 必須 | カスタム順 / 日付が近い順（日付未設定は末尾） |
| 日付管理 | 必須 | 説明会・面接日などを年・月・日のドロップダウンで設定 |
| 企業研究メモ | 必須 | 強み・顧客・競合相手を企業ごとに記録 |
| 複数URL管理 | 必須 | 公式URL・新卒採用HP・新卒採用マイページを個別管理 |
| マイページID/PW管理 | 必須 | 各企業のマイページログイン情報をメモとして保存 |

### 3.2 選考ステータス定義

ステータスは最大2つまで設定可能（ステータス①・ステータス②）。

| ステータス | 表示色 |
|-----------|--------|
| 説明会 | グレー |
| IS内定 | アンバー |
| IS不合格 | スレートグレー |
| ES提出 | ブルー |
| 一次面接/カジュアル面談 | シアン |
| 二次面接 | パープル |
| 三次面接以降 | ライトパープル |
| 最終面接 | ピンク |
| 内定 | グリーン |
| 入社検討候補 | エメラルド |
| 辞退 | オレンジ |
| 本選考不合格 | レッド |

### 3.3 企業詳細ページに表示する情報

- 企業名・業界・設定日付
- 公式URL・新卒採用HP・新卒採用マイページ（各リンク）
- マイページ ID
- 現在の選考ステータス①②（バッジ表示のみ・「変更する→」ボタンで編集画面へ）
- 付与されているタグ一覧
- 企業研究メモ（強み・顧客・競合相手）
- 備考
- メモ一覧（複数作成可）

### 3.4 企業登録・編集フォームの入力項目

| 項目 | 必須 | 備考 |
|------|------|------|
| 企業名 | ✅ | |
| 選考ステータス① | ✅ | デフォルト: 説明会 |
| 選考ステータス② | | 任意・なしも可 |
| 日付 | | 年・月・日のドロップダウン、×ボタンでクリア可 |
| 業界 | | 例: IT・Web、金融、メーカー |
| タグ | | 複数選択可 |
| 公式URL | | |
| 新卒採用HP | | |
| 新卒採用マイページ URL | | |
| マイページ ID | | メモとして保存 |
| マイページ パスワード | | 平文保存・取り扱い注意 |
| 強み | | 企業研究メモ |
| 顧客 | | 企業研究メモ |
| 競合相手 | | 企業研究メモ |
| 備考 | | 自由記述 |

> ⚠️ マイページパスワードは暗号化されずに保存されます。取り扱いにご注意ください。

## 4. タグ管理

### 4.1 機能一覧

| 機能 | 優先度 | 概要 |
|------|--------|------|
| タグの作成 | 必須 | タグ名・カラーを設定して新規作成 |
| タグの削除 | 必須 | 企業からのタグ付けも連動削除 |
| 企業へのタグ付け（複数可） | 必須 | 企業追加・編集ページからアサイン・解除 |
| タグでのフィルタリング | 必須 | 企業一覧ページでタグを選択して絞り込み |
| カラーのプレビュー | 必須 | 選択中のカラーをリングと丸でハイライト表示、タグ名と組み合わせたバッジをリアルタイムプレビュー |

### 4.2 タグ仕様

- 1企業に対して複数タグ付与可
- タグカラーはプリセット10色またはカスタムカラー（カラーピッカー）から選択
- 選択中のカラーは強調表示でひと目で確認可能
- タグはユーザーごとに独立して管理

## 5. メモ・テンプレート

### 5.1 機能一覧

| 機能 | 優先度 | 概要 |
|------|--------|------|
| 企業ごとのメモ入力 | 必須 | テキストエリアで自由記述（Monoフォント） |
| 複数メモの作成 | 必須 | 1企業に対して複数メモを作成可能 |
| メモの編集 | 必須 | タイトル・本文の更新・保存後に詳細画面へ自動遷移 |
| メモの削除 | 必須 | 確認ダイアログ付きで個別削除 |
| テンプレート選択 | 必須 | 選択すると書式が自動挿入、選択中はハイライト表示 |
| デフォルトテンプレートの提供 | 必須 | 6種類のテンプレートを用意 |

### 5.2 テンプレート一覧（6種）

| テンプレート名 | 主な項目 |
|---|---|
| 企業研究 | 事業内容・強み・志望理由・懸念点 |
| 面接メモ | 日時・形式・質問と回答・感想・次回準備 |
| ES・書類 | 設問と回答・提出期限・提出状況 |
| OB/OG訪問 | 日時・訪問者プロフィール・聞いた内容・学び |
| 説明会メモ | 日時・説明内容・印象・質問と回答・感想 |
| 自由メモ | フリーフォーマット |

### 5.3 テンプレート選択の挙動

- 内容が空の場合：選択と同時に書式を自動挿入
- 内容が入力済みの場合：確認ダイアログを表示してから置き換え

## 7. UI・ナビゲーション

### 7.1 サイドバー

- 開閉トグルボタン付き（`‹` / `›`）でアニメーション付き開閉
- 閉じるとメインコンテンツが全幅に広がる
- ユーザーのロゴ画像をサイドバー上部に表示（未設定時はデフォルトアイコン）
- ナビゲーション項目：ダッシュボード / 企業一覧 / タグ管理 / 設定

### 7.2 デザインシステム

ダーク系 × Linear風のモダンUI。

|------|----|------|
| `--bg` | `#0d0e11` | ベース背景 |
| `--bg-2` | `#13151a` | カード・サイドバー背景 |
| `--accent` | `#7c6af7` | メインアクセント（パープル） |

## 8. データモデル

### 8.1 テーブル定義

|-------|----|------|

|-------|----|------|

| status | text | 選考ステータス① |
| status2 | text | 選考ステータス②（任意） |
| industry | text | 業界 |
| url | text | 公式URL |
| recruit_url | text | 新卒採用HP |
| mypage_url | text | 新卒採用マイページURL |
| mypage_id | text | マイページID |
| mypage_password | text | マイページパスワード（平文） |
| strengths | text | 強み |
| customers | text | 顧客 |
| competitors | text | 競合相手 |
| notes | text | 備考 |
| event_date | timestamp | 説明会・面接などの日付 |
| created_at | timestamp | 作成日時 |
| updated_at | timestamp | 最終更新日時 |

#### `tags`
| カラム | 型 | 説明 |
|-------|----|------|
| id | uuid (PK) | タグID |
| user_id | uuid (FK) | 所有ユーザー |
| name | text | タグ名 |

#### `company_tags`（中間テーブル）
| カラム | 型 | 説明 |
|-------|----|------|
| company_id | uuid (FK) | 企業ID |

| カラム | 型 | 説明 |
|-------|----|------|

## 9. 画面構成

| パス | 画面名 | 主な機能 |
|------|--------|---------|
| `/` | ダッシュボード | ステータス別集計・最近更新した企業（最大10件） |

## 10. 技術スタック詳細

| レイヤー | 技術 | 備考 |
|---------|------|------|
| フレームワーク | Next.js 15 (App Router) | Server Actions + Client Components を使い分け |
| 言語 | TypeScript | strict モード |
| スタイリング | インラインCSS + CSSカスタム変数 | ダークテーマ（Linear風） |
| ORM | Drizzle ORM | 型安全・軽量 |
| データベース | Neon (PostgreSQL) | サーバーレス PostgreSQL |
| DB接続 | `@neondatabase/serverless` | neon-http ドライバ |
| 認証 | NextAuth.js v5 (Auth.js) | Credentials Provider・JWT戦略 |
| マイグレーション | Drizzle Kit | ビルド時自動実行（`tsx src/db/migrate.ts && next build`） |
| デプロイ | Vercel | mainブランチへのpushで自動デプロイ |

### 10.1 デプロイ構成

- **ホスティング**: Vercel
