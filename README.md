## 1. 概要

複数企業の選考状況・メモ・タグを一元管理し、就職活動を効率化するWebアプリケーション。

### 1.1 目的

- 複数企業の選考ステータスを可視化・追跡する
- 企業ごとのメモをテンプレートに沿って構造的に記録する
- タグでの分類・検索により情報を素早く参照できる
- 企業の強み・顧客・競合などの研究情報を一元管理する
- 各企業のマイページID・パスワードを安全に一元管理する

### 1.2 対象ユーザー

就職活動中の学生・転職活動中の社会人（個人利用）

## 2. ユーザー認証・設定

### 2.1 機能一覧

| 機能 | 優先度 | 概要 |
|------|--------|------|
| メール / パスワード登録・ログイン | 必須 | NextAuth.js v5 の Credentials Provider を使用 |
| ログアウト | 必須 | セッション破棄 |
| ロゴ・アイコンのアップロード | 必須 | 画像をBase64でDB保存、サイドバーに表示 |
| アカウント削除（退会） | 必須 | 全データ（企業・メモ・タグ）をCASCADEで完全削除 |
| パスワードリセット | Nice to have | メールリンクによるリセット |
| Google OAuth ログイン | Nice to have | NextAuth.js の Google Provider を使用 |

### 2.2 仕様詳細

- 未ログイン状態でのアクセスは `/auth/login` へリダイレクト
- セッションはJWT戦略で管理
- ユーザーデータは完全に分離（他ユーザーのデータは参照不可）
- アカウント削除は確認ダイアログを2段階で表示（誤操作防止）
- ロゴ画像はPNG / JPG / SVG に対応、推奨サイズ 256×256px

## 3. 企業管理

### 3.1 機能一覧

| 機能 | 優先度 | 概要 |
|------|--------|------|
| 企業の追加 | 必須 | 企業名・業界・各種URL・ステータス等を手入力して登録 |
| 企業の編集 | 必須 | 登録済み企業情報の更新 |
| 企業の削除 | 必須 | 関連するメモ・タグ付けも連動削除 |
| 選考ステータス管理 | 必須 | 企業詳細画面でボタンをクリックしてステータス変更 |
| 企業一覧表示 | 必須 | リスト形式で一覧表示 |
| フィルタリング | 必須 | ステータス・タグで絞り込み |
| キーワード検索 | 必須 | 企業名でのキーワード検索 |
| 企業研究メモ | 必須 | 強み・顧客・競合相手を企業ごとに記録 |
| 複数URL管理 | 必須 | 公式URL・新卒採用HP・新卒採用マイページを個別管理 |
| マイページID/PW管理 | 必須 | 各企業のマイページログイン情報をメモとして保存 |
| ステータス変更履歴 | Nice to have | いつステータスが変わったかを記録・表示 |

### 3.2 選考ステータス定義

| ステータス | 表示色 |
|-----------|--------|
| 説明会 | グレー |
| IS参加 | インディゴ |
| ES提出 | ブルー |
| 一次面接/カジュアル面談 | シアン |
| 二次面接 | パープル |
| 三次面接以降 | ライトパープル |
| 最終面接 | ピンク |
| 内定 | グリーン |
| 入社検討候補 | エメラルド |
| 辞退 | オレンジ |
| 不合格 | レッド |

### 3.3 企業詳細ページに表示する情報

- 企業名・業界
- 公式URL・新卒採用HP・新卒採用マイページ（各リンク）
- マイページ ID
- 現在の選考ステータス（ボタンクリックで即時変更）
- 付与されているタグ一覧
- 企業研究メモ（強み・顧客・競合相手）
- 備考
- メモ一覧（複数作成可）

## 4. タグ管理

### 4.1 機能一覧

| 機能 | 優先度 | 概要 |
|------|--------|------|
| タグの作成 | 必須 | タグ名・カラーを設定して新規作成 |
| タグの削除 | 必須 | 企業からのタグ付けも連動削除 |
| 企業へのタグ付け（複数可） | 必須 | 企業追加・編集ページからタグをアサイン・解除 |
| タグでのフィルタリング | 必須 | 企業一覧ページでタグを選択して絞り込み |
| タグの編集 | Nice to have | タグ名・カラーの変更 |

### 4.2 タグ仕様

- 1企業に対して複数タグ付与可
- タグカラーはプリセット10色またはカスタムカラー（カラーピッカー）から選択
- タグはユーザーごとに独立して管理

## 5. メモ・テンプレート

### 5.1 機能一覧

| 機能 | 優先度 | 概要 |
|------|--------|------|
| 企業ごとのメモ入力 | 必須 | テキストエリアで自由記述（Monoフォント） |
| 複数メモの作成 | 必須 | 1企業に対して複数メモを作成可能 |
| メモの編集 | 必須 | タイトル・本文の更新 |
| メモの削除 | 必須 | 個別削除 |
| テンプレート選択 | 必須 | メモ作成時にテンプレートタイプを選択、内容が自動挿入 |
| デフォルトテンプレートの提供 | 必須 | 6種類のテンプレートを用意 |
| テンプレートのカスタマイズ | Nice to have | ユーザー独自のテンプレートを作成・編集 |
| Markdown 記法のサポート | Nice to have | 記述をリッチに表示 |

### 5.2 デフォルトテンプレート（6種）

| テンプレート名 | 主な項目 |
|---|---|
| 企業研究 | 事業内容・強み・志望理由・懸念点 |
| 面接メモ | 日時・形式・質問と回答・感想・次回準備 |
| ES・書類 | 設問と回答・提出期限・提出状況 |
| OB/OG訪問 | 日時・訪問者プロフィール・聞いた内容・学び |
| 説明会メモ | 日時・説明内容・印象・質問と回答・感想 |
| 自由メモ | フリーフォーマット |

## 7. データモデル

### 7.1 テーブル定義

#### `users`
| カラム | 型 | 説明 |
|-------|----|------|
| id | uuid (PK) | ユーザーID |
| email | text (unique) | メールアドレス |
| email_verified | timestamp | メール認証日時 |
| password_hash | text | ハッシュ化済みパスワード |
| name | text | 表示名 |
| image | text | プロフィール画像URL |
| logo_base64 | text | サイドバー表示用ロゴ（Base64） |
| created_at | timestamp | 作成日時 |

#### `companies`
| カラム | 型 | 説明 |
|-------|----|------|
| id | uuid (PK) | 企業ID |
| user_id | uuid (FK) | 所有ユーザー |
| name | text | 企業名 |
| status | text | 選考ステータス |
| industry | text | 業界 |
| url | text | 公式URL |
| recruit_url | text | 新卒採用HP |
| mypage_url | text | 新卒採用マイページURL |
| mypage_id | text | マイページID |
| mypage_password | text | マイページパスワード（平文） |
| strengths | text | 強み（企業研究メモ） |
| customers | text | 顧客（企業研究メモ） |
| competitors | text | 競合相手（企業研究メモ） |
| notes | text | 備考 |
| created_at | timestamp | 作成日時 |
| updated_at | timestamp | 最終更新日時 |

#### `tags`
| カラム | 型 | 説明 |
|-------|----|------|
| id | uuid (PK) | タグID |
| user_id | uuid (FK) | 所有ユーザー |
| name | text | タグ名 |
| color | text | カラーコード（HEX） |

#### `company_tags`（中間テーブル）
| カラム | 型 | 説明 |
|-------|----|------|
| company_id | uuid (FK) | 企業ID |
| tag_id | uuid (FK) | タグID |

#### `memos`
| カラム | 型 | 説明 |
|-------|----|------|
| id | uuid (PK) | メモID |
| company_id | uuid (FK) | 対象企業 |
| template_type | text | テンプレート種別 |
| title | text | メモタイトル |
| content | text | メモ本文 |
| created_at | timestamp | 作成日時 |
| updated_at | timestamp | 最終更新日時 |

#### NextAuth用テーブル
`accounts` / `sessions` / `verification_tokens` — NextAuth.js v5 の DrizzleAdapter が要求する標準テーブル。

## 8. 画面構成

| パス | 画面名 | 主な機能 |
|------|--------|---------|
| `/` | ダッシュボード | ステータス別集計カード・最近更新した企業一覧 |
| `/companies` | 企業一覧 | 検索・ステータス/タグフィルタ・新規追加ボタン |
| `/companies/new` | 企業追加 | 手入力フォーム（基本情報・URL・マイページ情報・企業研究メモ） |
| `/companies/[id]` | 企業詳細 | ステータス変更・タグ・企業研究メモ・マイページ情報・メモ一覧 |
| `/companies/[id]/edit` | 企業編集 | 全項目の編集フォーム |
| `/companies/[id]/memos/new` | メモ作成 | テンプレート選択・タイトル・本文入力 |
| `/companies/[id]/memos/[memoId]` | メモ詳細・編集 | メモの閲覧・編集・削除 |
| `/tags` | タグ管理 | タグ一覧・作成（名前・カラー）・削除 |
| `/settings` | 設定 | ロゴアップロード・アカウント削除 |
| `/auth/login` | ログイン | メール/パスワード認証フォーム |
| `/auth/register` | 新規登録 | アカウント作成フォーム |

## 9. 技術スタック詳細

| レイヤー | 技術 | 備考 |
|---------|------|------|
| フレームワーク | Next.js 15 (App Router) | Server Actions を積極活用 |
| 言語 | TypeScript | strict モード |
| スタイリング | インラインCSSカスタム変数 | ダークテーマ（Linear風） |
| ORM | Drizzle ORM | 型安全・軽量、Neonとの相性良好 |
| データベース | Neon (PostgreSQL) | サーバーレス PostgreSQL |
| DB接続 | `@neondatabase/serverless` | neon-http ドライバ使用 |
| 認証 | NextAuth.js v5 (Auth.js) | Credentials Provider、JWT戦略 |
| マイグレーション | Drizzle Kit | ビルド時に自動実行（`tsx src/db/migrate.ts && next build`） |
| デプロイ | Vercel | GitHubと連携、mainブランチへのpushで自動デプロイ |

### 9.1 デザインシステム

ダーク系 × Linear風のモダンUIを採用。開閉可能なサイドバー付き。

| 変数 | 値 | 用途 |
|------|----|------|
| `--bg` | `#0d0e11` | ベース背景 |
| `--bg-2` | `#13151a` | カード・サイドバー背景 |
| `--accent` | `#7c6af7` | メインアクセント（パープル） |
| `--cyan` | `#22d3ee` | サブアクセント |
| `--text` | `#e8eaf0` | メインテキスト |
| `--text-3` | `#5a6070` | サブテキスト・ラベル |

### 9.2 デプロイ構成

- **ホスティング**: Vercel（自動デプロイ）
- **データベース**: Neon（Vercel Storageとして連携）
- **本番URL**: https://job-hunting-app-mauve.vercel.app/
- **CI/CD**: `main` ブランチへのpushで自動ビルド・デプロイ
