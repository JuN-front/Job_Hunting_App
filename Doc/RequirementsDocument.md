## 1. 概要

複数企業の選考状況・メモ・タグを一元管理し、就職活動を効率化するWebアプリケーション。

### 1.1 目的

- 複数企業の選考ステータスを可視化・追跡する
- 企業ごとのメモをテンプレートに沿って構造的に記録する
- タグでの分類・検索により情報を素早く参照できる

### 1.2 対象ユーザー

就職活動中の学生・転職活動中の社会人（個人利用）

---

## 2. ユーザー認証

### 2.1 機能一覧

| 機能 | 優先度 | 概要 |
|------|--------|------|
| メール / パスワード登録・ログイン | 必須 | NextAuth.js v5 の Credentials Provider を使用 |
| ログアウト | 必須 | セッション破棄 |
| パスワードリセット | Nice to have | メールリンクによるリセット |
| Google OAuth ログイン | Nice to have | NextAuth.js の Google Provider を使用 |

### 2.2 仕様詳細

- 未ログイン状態でのアクセスは `/auth/login` へリダイレクト
- セッションはサーバーサイドで管理（JWT or Database Session）
- ユーザーデータは完全に分離（他ユーザーのデータは参照不可）

## 3. 企業管理

### 3.1 機能一覧

| 機能 | 優先度 | 概要 |
|------|--------|------|
| 企業の追加 | 必須 | 企業名・業界・URL・ステータスを入力して登録 |
| 企業の編集 | 必須 | 登録済み企業情報の更新 |
| 企業の削除 | 必須 | 関連するメモ・タグ付けも連動削除 |
| 選考ステータス管理 | 必須 | ステータスをドロップダウンで変更 |
| 企業一覧表示 | 必須 | カード形式またはテーブル形式で一覧表示 |
| フィルタリング | 必須 | ステータス・タグ・業界で絞り込み |
| キーワード検索 | 必須 | 企業名でインクリメンタル検索 |
| ステータス変更履歴 | Nice to have | いつステータスが変わったかを記録・表示 |

### 3.2 選考ステータス定義

```
説明会 → ES提出 → 一次面接 → 二次面接 → 最終面接 → 内定 → 入社予定
                                                              → 辞退
                                          ↓（各ステータスから）
                                        不合格
```

| ステータス | 表示色（案） |
|-----------|------------|
| 説明会 | グレー |
| ES提出 | ブルー |
| 一次面接 | シアン |
| 二次面接 | インディゴ |
| 最終面接 | パープル |
| 内定 | グリーン |
| 入社予定 | エメラルド |
| 辞退 | オレンジ |
| 不合格 | レッド |

### 3.3 企業詳細ページに表示する情報

- 企業名・公式URL・業界
- 現在の選考ステータス
- 付与されているタグ一覧
- 関連メモ一覧（テンプレートタイプ別）
- ステータス変更履歴（Nice to have）

## 4. タグ管理

### 4.1 機能一覧

| 機能 | 優先度 | 概要 |
|------|--------|------|
| タグの作成 | 必須 | タグ名・カラーを設定して新規作成 |
| タグの編集 | 必須 | タグ名・カラーの変更 |
| タグの削除 | 必須 | 企業からのタグ付けも連動削除 |
| 企業へのタグ付け（複数可） | 必須 | 企業詳細ページからタグをアサイン・解除 |
| タグでのフィルタリング | 必須 | 企業一覧ページでタグを選択して絞り込み |

### 4.2 タグ仕様

- 1企業に対して複数タグ付与可
- タグカラーはプリセット（例：赤・青・緑・黄・紫・ピンクなど 10色）または HEX 入力
- タグはユーザーごとに独立して管理

### 4.3 タグ例（初期プリセット候補）

| タグ名 | 用途例 |
|--------|--------|
| 第一志望 | 特に行きたい企業 |
| IT・Web | 業界分類 |
| メーカー | 業界分類 |
| 大手 | 規模分類 |
| ベンチャー | 規模分類 |
| 締切近い | 緊急度管理 |
| OB訪問済 | アクション済みフラグ |

## 5. メモ・テンプレート

### 5.1 機能一覧

| 機能 | 優先度 | 概要 |
|------|--------|------|
| 企業ごとのメモ入力 | 必須 | テキストエリアで自由記述 |
| テンプレート選択 | 必須 | メモ作成時にテンプレートタイプを選択 |
| デフォルトテンプレートの提供 | 必須 | 事前定義されたテンプレートを利用可能 |
| テンプレートのカスタマイズ | Nice to have | ユーザー独自のテンプレートを作成・編集 |
| Markdown 記法のサポート | Nice to have | 記述をリッチに表示 |

### 5.2 デフォルトテンプレート定義

#### テンプレート①：企業研究メモ
```
## 事業内容
（ここに記入）

## 強み・特徴
（ここに記入）

## 志望理由
（ここに記入）

## 懸念点・確認したいこと
（ここに記入）
```

#### テンプレート②：面接メモ
```
## 面接日時
（ここに記入）

## 面接形式
（例：集団 / 個人 / オンライン）

## 質問と回答
Q: 
A: 

## 感想・反省
（ここに記入）

## 次回に向けての準備
（ここに記入）
```

#### テンプレート③：ES・提出書類メモ
```
## 設問と回答

### 設問1
Q: 
A: 

### 設問2
Q: 
A: 

## 提出期限
（ここに記入）

## 提出状況
（例：未提出 / 提出済）
```

#### テンプレート④：OB/OG訪問メモ
```
## 訪問日時・場所
（ここに記入）

## 訪問者プロフィール
（役職・部署など）

## 聞いた内容
（ここに記入）

## 感想・学び
（ここに記入）
```

## 7. データモデル

### 7.1 テーブル定義

#### `users`
| カラム | 型 | 説明 |
|-------|----|------|
| id | uuid (PK) | ユーザーID |
| email | text (unique) | メールアドレス |
| password_hash | text | ハッシュ化済みパスワード |
| created_at | timestamp | 作成日時 |

#### `companies`
| カラム | 型 | 説明 |
|-------|----|------|
| id | uuid (PK) | 企業ID |
| user_id | uuid (FK) | 所有ユーザー |
| name | text | 企業名 |
| status | text | 選考ステータス |
| industry | text | 業界 |
| url | text | 公式URL |
| notes | text | 備考（任意） |
| created_at | timestamp | 作成日時 |
| updated_at | timestamp | 最終更新日時 |

#### `tags`
| カラム | 型 | 説明 |
|-------|----|------|
| id | uuid (PK) | タグID |
| user_id | uuid (FK) | 所有ユーザー |
| name | text | タグ名 |
| color | text | カラーコード（HEX） |

#### `company_tags`（中間テーブル）
| カラム | 型 | 説明 |
|-------|----|------|
| company_id | uuid (FK) | 企業ID |
| tag_id | uuid (FK) | タグID |

#### `memos`
| カラム | 型 | 説明 |
|-------|----|------|
| id | uuid (PK) | メモID |
| company_id | uuid (FK) | 対象企業 |
| template_type | text | テンプレート種別 |
| content | text | メモ本文 |
| created_at | timestamp | 作成日時 |
| updated_at | timestamp | 最終更新日時 |

#### `templates`（Nice to have）
| カラム | 型 | 説明 |
|-------|----|------|
| id | uuid (PK) | テンプレートID |
| user_id | uuid (FK) | 所有ユーザー |
| name | text | テンプレート名 |
| fields | jsonb | テンプレート構造（JSON） |

## 8. 画面構成

| パス | 画面名 | 主な機能 |
|------|--------|---------|
| `/` | ダッシュボード | ステータス集計・最近の企業一覧 |
| `/companies` | 企業一覧 | 検索・フィルタ・タグ絞り込み・新規追加 |
| `/companies/new` | 企業追加 | 企業情報の入力フォーム |
| `/companies/[id]` | 企業詳細 | ステータス変更・タグ編集・メモ一覧 |
| `/companies/[id]/memos/new` | メモ作成 | テンプレート選択・本文入力 |
| `/tags` | タグ管理 | タグ一覧・作成・編集・削除 |
| `/templates` | テンプレート管理 | テンプレートCRUD（Nice to have） |
| `/auth/login` | ログイン | 認証フォーム |
| `/auth/register` | 新規登録 | アカウント作成フォーム |

## 9. 技術スタック詳細

| レイヤー | 技術 | 備考 |
|---------|------|------|
| フレームワーク | Next.js 14 (App Router) | Server Actions を積極活用 |
| 言語 | TypeScript | strict モード推奨 |
| スタイリング | Tailwind CSS + shadcn/ui | コンポーネントUIライブラリ |
| ORM | Drizzle ORM | 型安全・軽量、Neonとの相性良好 |
| データベース | Neon (PostgreSQL) | サーバーレス PostgreSQL |
| DB接続 | `@neondatabase/serverless` | Edge Runtime 対応 |
| 認証 | NextAuth.js v5 (Auth.js) | Credentials + OAuth |
| デプロイ | Vercel | Next.js との親和性が高い |
